# 宠物健康管家系统开题报告

## 1. 项目概述

### 1.1 项目背景
随着人们生活水平的提高和宠物文化的普及，越来越多的家庭开始饲养宠物。然而，现代快节奏的生活使得宠物主人往往缺乏足够的时间和专业知识来科学地管理宠物的健康状况。传统的宠物健康管理方式存在以下痛点：

- 缺乏系统性的健康档案管理
- 重要的疫苗接种、驱虫等时间节点容易遗忘
- 健康数据分散，难以形成完整的成长轨迹
- 宠物医疗服务信息不对称，寻找优质服务困难

### 1.2 项目意义
本项目旨在开发一套基于微信小程序的宠物健康管家系统，通过数字化手段帮助宠物主人更好地管理宠物健康，具有以下重要意义：

**社会价值：**
- 提升宠物健康管理水平，促进人宠和谐共处
- 规范宠物健康管理流程，推动行业标准化发展
- 降低因健康管理不当导致的宠物疾病发生率

**技术价值：**
- 探索移动端健康管理系统的设计与实现
- 实践微服务架构在垂直领域应用
- 积累宠物健康大数据分析经验

**商业价值：**
- 为宠物医疗服务业提供数字化转型方案
- 构建宠物健康管理生态平台基础
- 创造可持续的商业模式

```java
// JWT工具类核心方法
@Component
public class JwtTokenUtil {
    private static final String SECRET_KEY = "pet_health_secret_key_2026";
    private static final long EXPIRATION_TIME = 86400000; // 24小时
    
    // 生成Token
    public String generateToken(UserDetails userDetails) {
        Map<String, Object> claims = new HashMap<>();
        claims.put("userId", ((User) userDetails).getUserId());
        claims.put("username", userDetails.getUsername());
        return createToken(claims, userDetails.getUsername());
    }
    
    // 验证Token
    public boolean validateToken(String token, UserDetails userDetails) {
        final String username = getUsernameFromToken(token);
        return (username.equals(userDetails.getUsername()) && !isTokenExpired(token));
    }
}

// 认证拦截器
@Component
public class AuthInterceptor implements HandlerInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest request, 
                           HttpServletResponse response, 
                           Object handler) throws Exception {
        String token = request.getHeader("Authorization");
        if (token != null && token.startsWith("Bearer ")) {
            token = token.substring(7);
            // 验证Token并设置用户信息到请求属性
            Integer userId = jwtTokenUtil.getUserIdFromToken(token);
            request.setAttribute("currentUserId", userId);
            return true;
        }
        response.setStatus(HttpStatus.UNAUTHORIZED.value());
        return false;
    }
}
```

#### 5.2.3 文件上传与存储系统

**文件上传架构：**
```
用户上传 → 文件验证 → 生成唯一文件名 → 存储到服务器 → 记录文件信息 → 返回访问URL
    ↓         ↓         ↓         ↓         ↓         ↓
  格式检查   大小限制   安全命名   分类存储   数据库存储   CDN加速
```

**核心实现代码：**
```java
@Service
public class FileServiceImpl implements FileService {
    
    @Value("${file.upload.path}")
    private String uploadPath;
    
    @Value("${file.access.url}")
    private String fileAccessUrl;
    
    // 文件上传主方法
    public FileUploadResponseDTO uploadFile(MultipartFile file, 
                                          FileUploadRequestDTO requestDTO, 
                                          Integer userId) {
        // 1. 文件验证
        validateFile(file);
        
        // 2. 生成存储路径
        String modulePath = FileUtils.getModulePath(requestDTO.getModuleType());
        String fileName = generateUniqueFileName(file);
        String relativePath = StringUtil.joinPath(modulePath, 
                                                requestDTO.getBusinessId().toString(), 
                                                fileName);
        
        // 3. 保存文件
        Path fullPath = Paths.get(uploadPath, relativePath);
        Files.createDirectories(fullPath.getParent());
        Files.write(fullPath, file.getBytes());
        
        // 4. 记录文件信息
        FileInfo fileInfo = new FileInfo();
        fileInfo.setOriginalName(file.getOriginalFilename());
        fileInfo.setFileUrl(fileAccessUrl + relativePath);
        fileInfo.setFileSize(file.getSize());
        fileInfo.setFileType(file.getContentType());
        fileInfo.setModuleType(requestDTO.getModuleType());
        fileInfo.setBusinessId(requestDTO.getBusinessId());
        fileInfo.setUploaderId(userId);
        
        fileInfoMapper.insert(fileInfo);
        
        return convertToFileUploadResponse(fileInfo);
    }
    
    // 文件验证
    private void validateFile(MultipartFile file) {
        if (file.isEmpty()) {
            throw new BusinessException("文件不能为空");
        }
        
        if (file.getSize() > 5 * 1024 * 1024) { // 5MB限制
            throw new BusinessException("文件大小不能超过5MB");
        }
        
        String contentType = file.getContentType();
        List<String> allowedTypes = Arrays.asList(
            "image/jpeg", "image/png", "image/gif",
            "application/pdf", "application/msword"
        );
        
        if (!allowedTypes.contains(contentType)) {
            throw new BusinessException("不支持的文件类型: " + contentType);
        }
    }
}
```

**存储策略：**
- 按模块类型分类存储（宠物头像、体检报告、疫苗记录等）
- 生成UUID文件名避免冲突
- 支持图片压缩和格式转换
- 集成CDN加速文件访问

#### 5.2.4 智能提醒系统

**提醒触发机制：**
```
定时任务扫描 → 查询即将到期提醒 → 发送通知 → 更新提醒状态
    ↓              ↓              ↓              ↓
每小时执行      提前24小时提醒    微信模板消息    标记已通知
```

**核心实现代码：**
```java
@Component
@EnableScheduling
public class ReminderTask {
    
    @Autowired
    private ReminderService reminderService;
    
    @Autowired
    private WechatMessageService wechatMessageService;
    
    // 每小时执行一次提醒检查
    @Scheduled(cron = "0 0 * * * ?")
    public void checkAndSendReminders() {
        log.info("开始执行提醒任务");
        
        // 查询未来24小时内到期的提醒
        List<Reminder> upcomingReminders = reminderService.getUpcomingReminders(24);
        
        for (Reminder reminder : upcomingReminders) {
            if (!reminder.getNotificationSent()) {
                try {
                    // 发送微信模板消息
                    sendWechatReminder(reminder);
                    
                    // 更新提醒状态
                    reminder.setNotificationSent(true);
                    reminderService.updateById(reminder);
                    
                    log.info("提醒发送成功: reminderId={}", reminder.getReminderId());
                } catch (Exception e) {
                    log.error("发送提醒失败: reminderId={}", reminder.getReminderId(), e);
                }
            }
        }
    }
    
    private void sendWechatReminder(Reminder reminder) {
        // 构造微信模板消息
        WechatTemplateMessage message = new WechatTemplateMessage();
        message.setToUser(getUserOpenId(reminder.getUserId()));
        message.setTemplateId("reminder_template_id");
        message.addData("first", "您有一条宠物健康提醒");
        message.addData("keyword1", reminder.getTitle());
        message.addData("keyword2", formatDate(reminder.getDueDate()));
        message.addData("remark", reminder.getContent());
        
        wechatMessageService.sendTemplateMessage(message);
    }
}
```

**提醒算法特点：**
- 支持一次性提醒和周期性提醒
- 智能去重和冲突检测
- 多渠道通知（微信、短信、邮件）
- 提醒历史记录和统计分析

```java
        params.put("key", apiKey);
        params.put("address", address);

    // 计算两点间距离
    public double calculateDistance(BigDecimal startLon, BigDecimal startLat,
                                  BigDecimal endLon, BigDecimal endLat) {
        double radLat1 = startLat.doubleValue() * Math.PI / 180.0;
        double radLat2 = endLat.doubleValue() * Math.PI / 180.0;
        double deltaRadLat = radLat1 - radLat2;
        double deltaRadLon = (startLon.doubleValue() - endLon.doubleValue()) * Math.PI / 180.0;
        
        double distance = 2 * Math.asin(Math.sqrt(
            Math.pow(Math.sin(deltaRadLat / 2), 2) +
            Math.cos(radLat1) * Math.cos(radLat2) *
            Math.pow(Math.sin(deltaRadLon / 2), 2)
        ));
        
        distance = distance * 6378.137; // 地球半径
        distance = Math.round(distance * 10000) / 10000.0; // 保留4位小数
        return distance;
    }
}
```

#### 5.2.6 数据缓存与性能优化

**Redis缓存策略：**
```java
@Configuration
public class RedisConfig {
    
    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(factory);
        
        // 设置序列化器
        Jackson2JsonRedisSerializer<Object> serializer = 
            new Jackson2JsonRedisSerializer<>(Object.class);
        ObjectMapper mapper = new ObjectMapper();
        mapper.setVisibility(PropertyAccessor.ALL, JsonAutoDetect.Visibility.ANY);
        mapper.activateDefaultTyping(LazyCollectionResolver.instance(), 
                                   ObjectMapper.DefaultTyping.NON_FINAL);
        serializer.setObjectMapper(mapper);
        
        template.setValueSerializer(serializer);
        template.setKeySerializer(new StringRedisSerializer());
        template.afterPropertiesSet();
        return template;
    }
    
    // 缓存管理器配置
    @Bean
    public CacheManager cacheManager(RedisConnectionFactory factory) {
        RedisCacheConfiguration config = RedisCacheConfiguration.defaultCacheConfig()
            .entryTtl(Duration.ofHours(1))
            .serializeKeysWith(RedisSerializationContext.SerializationPair
                             .fromSerializer(new StringRedisSerializer()))
            .serializeValuesWith(RedisSerializationContext.SerializationPair
                               .fromSerializer(new GenericJackson2JsonRedisSerializer()));
        
        return RedisCacheManager.builder(factory)
            .cacheDefaults(config)
            .build();
    }
}
```

```javascript
// utils/request.js - 统一请求封装
class Request {
  constructor() {
    this.baseURL = 'https://api.example.com'
    this.timeout = 10000
  }
  
  // 请求拦截器
  interceptors = {
    request: (config) => {
      // 添加认证token
      const token = wx.getStorageSync('token')
      if (token) {
        config.header = config.header || {}
        config.header['Authorization'] = `Bearer ${token}`
      }
      return config
    },
    
    response: (response) => {
      // 统一错误处理
      if (response.statusCode === 401) {
        // token过期，跳转登录
        wx.redirectTo({ url: '/pages/login/login' })
        return Promise.reject(response)
      }
      return response.data
    }
  }
  
  // 核心请求方法
  request(options) {
    return new Promise((resolve, reject) => {
      const config = this.interceptors.request(options)
      
      wx.request({
        ...config,
        url: this.baseURL + config.url,
        timeout: this.timeout,
        success: (res) => {
          const result = this.interceptors.response(res)
          resolve(result)
        },
        fail: (err) => {
          reject(err)
        }
      })
    })
  }
}

// 导出实例
export default new Request()
```

### 6.3 技术难点与解决方案

#### 6.3.1 定时任务可靠性保障
**难点分析：**
- 任务执行失败如何重试
- 分布式环境下任务重复执行
- 系统重启后任务恢复

**解决方案：**
```java
@Component
public class ReliableReminderTask {
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    // 分布式锁确保任务不重复执行
    @Scheduled(cron = "0 0 * * * ?")
    public void executeWithLock() {
        String lockKey = "reminder_task_lock";
        String lockValue = UUID.randomUUID().toString();
        
        try {
            // 获取分布式锁
            Boolean acquired = redisTemplate.opsForValue()
                .setIfAbsent(lockKey, lockValue, Duration.ofMinutes(5));
            
            if (Boolean.TRUE.equals(acquired)) {
                // 执行任务
                executeReminderTask();
            }
        } finally {
            // 释放锁
            String currentValue = redisTemplate.opsForValue().get(lockKey);
            if (lockValue.equals(currentValue)) {
                redisTemplate.delete(lockKey);
            }
        }
    }
    
    // 任务失败重试机制
    @Retryable(value = {Exception.class}, maxAttempts = 3, backoff = @Backoff(delay = 1000))
    private void executeReminderTask() {
        // 核心业务逻辑
        reminderService.processReminders();
    }
}
```

```java
    public byte[] compressImage(byte[] imageData, String format) {
        try {
            BufferedImage image = ImageIO.read(new ByteArrayInputStream(imageData));
            ByteArrayOutputStream outputStream = new ByteArrayOutputStream();
            
            // 质量压缩
            ImageWriter writer = ImageIO.getImageWritersByFormatName(format).next();
            ImageWriteParam param = writer.getDefaultWriteParam();

            writer.dispose();
            
            return outputStream.toByteArray();

        }
    }
```
