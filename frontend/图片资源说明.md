# 图片资源说明文档

---

## 🎨 TabBar 图标（必需）

所有TabBar图标建议使用 **PNG格式**，**81×81px**，**24位真彩色**

### 1. 首页图标
- **未选中**: `images/tab/home.png`
- **已选中**: `images/tab/home-active.png`
- **设计建议**: 房子图标，可爱风格

### 2. 宠物图标
- **未选中**: `images/tab/pets.png`
- **已选中**: `images/tab/pets-active.png`
- **设计建议**: 爪印或宠物剪影

### 3. 健康图标
- **未选中**: `images/tab/health.png`
- **已选中**: `images/tab/health-active.png`
- **设计建议**: 心形或十字标志

### 4. 提醒图标
- **未选中**: `images/tab/reminder.png`
- **已选中**: `images/tab/reminder-active.png`
- **设计建议**: 铃铛或闹钟

### 5. 服务图标
- **未选中**: `images/tab/map.png`
- **已选中**: `images/tab/map-active.png`
- **设计建议**: 地图定位标志

## 🖼️ 功能图标（推荐）

建议使用 **PNG格式**，**128×128px**

### 默认宠物头像
- **路径**: `images/default-pet.png`
- **用途**: 宠物默认头像
- **设计建议**: 可爱的宠物剪影或插画

### 空状态图片
- **路径**: `images/empty.png`
- **用途**: 列表为空时的占位图
- **设计建议**: 简约的空状态插画

### 加载动画
- **路径**: `images/loading.gif`
- **用途**: 页面加载时显示
- **设计建议**: 粉色旋转动画

## 🎯 获取图片资源的方案

### 方案一：免费图标库（推荐）

1. **Iconfont（阿里图标库）**
   - 网址: https://www.iconfont.cn/
   - 搜索关键词: "宠物"、"健康"、"提醒"、"地图"
   - 下载PNG格式图标

2. **Flaticon**
   - 网址: https://www.flaticon.com/
   - 大量免费图标资源

3. **IconFinder**
   - 网址: https://www.iconfinder.com/
   - 高质量图标

### 方案二：在线生成

1. **App Icon Generator**
   - 可以生成各种尺寸的图标
   - https://appicon.co/

2. **Canva**
   - 在线设计工具
   - https://www.canva.com/
   - 提供图标模板

### 方案三：AI生成（推荐）

使用AI工具生成可爱的宠物图标：
- **Midjourney**
- **DALL-E**
- **Stable Diffusion**

提示词示例：
```
Cute minimalist pet health app icon, flat design, pink color scheme, 
81x81 pixels, PNG format, mobile app tabbar icon
```

## 🎨 设计风格建议

### 配色方案
- **主色**: #FF6B9D（粉色）
- **辅助色**: #FFB6C1（浅粉色）
- **背景色**: #FFF5F7（淡粉色）
- **白色**: #FFFFFF
- **灰色**: #999999

### 设计风格
- **圆润**: 所有图标采用圆角设计
- **扁平**: 扁平化设计，不要过多渐变
- **可爱**: 选择可爱、温馨的图标
- **统一**: 保持设计风格统一

### 图标规范
- TabBar图标: **81×81px**
- 功能图标: **128×128px**
- 背景透明: PNG格式带透明通道
- 颜色模式: RGB

## ⚠️ 注意事项

1. **TabBar图标是必需的**，必须准备才能正常运行
2. **图标尺寸要准确**，81×81px是官方推荐尺寸
3. **文件命名要一致**，严格按照上面的路径和文件名
4. **图片大小要优化**，单个图标建议不超过50KB
5. **版权问题**，使用免费图标库时注意授权

## 🔧 临时解决方案

如果暂时没有准备图片资源，可以使用以下临时方案：

### 方案一：使用纯色方块
创建简单的PNG图片，纯色填充作为占位

### 方案二：注释掉TabBar
在`app.json`中暂时注释掉tabBar配置，使用导航代替

### 方案三：使用emoji作为图标
修改页面，使用emoji代替图标图标
